# في صدور

تطبيق أندرويد شخصي لحفظ القرآن الكريم بخطة يومية: وجه أو وجهان أو ثلاثة أوجه، مع الربط والمراجعة والجولات.

- **خطة اليوم:** تكرار الأمس، السماع، التفسير، التكرار بالعداد، التسجيل، الربط، المراجعة.
- **تغيير المقدار في أي وقت:** يُعاد حساب الربط والمراجعة من الأوجه المحفوظة فعلًا.
- **نهاية يوم مخصصة:** منتصف الليل أو أي ساعة (مثل ٤ فجرًا)، مع عداد للوقت المتبقي.
- **أيام الإجازة:** الجمعة افتراضيًا، وأيام المرض أو السفر: ربط ومراجعة فقط.
- **الإحصائيات:** المحفوظ، الاستمرار، الغياب، موعد الختم المتوقع.

## قواعد الخطة

القواعد في `app/src/main/java/com/fisudur/app/engine/PlanEngine.kt`، واختباراتها في
`app/src/test` تعيد تشغيل الجداول المطبوعة الثلاثة يومًا بيوم.

## البناء والتحديث

كل دفع إلى `main` يشغّل الاختبارات ويبني APK موقّعًا وينشره في Releases باسم `v1.0.<رقم البناء>`.
التطبيق يتحقق من آخر إصدار من شاشة الإعدادات.

يحتاج المستودع سرّين: `KEYSTORE_BASE64` و`KEYSTORE_PASSWORD`.
